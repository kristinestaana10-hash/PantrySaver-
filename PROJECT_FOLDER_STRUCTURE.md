# Project Folder Structure

## Overview
This document outlines the main folders and files in the PantrySaver project.

## Root Structure
- android/ - Android platform project files
- build/ - Generated build artifacts
- ios/ - iOS platform project files
- lib/ - Main application source code
- linux/ - Linux platform project files
- macos/ - macOS platform project files
- test/ - Unit and widget tests
- web/ - Web platform files
- windows/ - Windows platform files
- analysis_options.yaml - Dart/Flutter linting rules
- pubspec.yaml - Project dependencies and metadata
- README.md - Project description and usage information

## Application Source Structure
- lib/main.dart - Application entry point
- lib/models/ - Data models
- lib/providers/ - State management providers
- lib/screens/ - UI screens
- lib/services/ - Business logic and external services
- lib/utils/ - Helper utilities
- lib/widgets/ - Reusable UI components
- lib/firebase_options.dart - Firebase configuration
